# HPC AI — 270 Day Journey

A standalone Android/Jetpack Compose learning-book app for mastering HPC and AI infrastructure in 270 days.

## V1
Days 1–15 are fully authored. The app is designed as a two-page-per-day handwritten-notes experience, with illustrations, key ideas, practical tasks, progress tracking, and sequential completion.

## Planned curriculum
1. Days 1–15: HPC/AI infrastructure overview
2. Days 16–45: Linux, Bash, Python
3. Days 46–70: Networking, RDMA, RoCE, InfiniBand
4. Days 71–105: HPC architecture, Slurm, MPI/OpenMP
5. Days 106–150: NFS, S3, NVMe, NVMe-oF, distributed storage
6. Days 151–190: Lustre, GPFS/Storage Scale, BeeGFS
7. Days 191–215: Ceph
8. Days 216–240: FIO, IOR, benchmarking and performance
9. Days 241–255: GPUs, NCCL, AI pipelines and AI storage
10. Days 256–270: DDN, WEKA, VAST, NVIDIA AI infrastructure, architecture and troubleshooting

This project is intentionally separate from the ABC Adventure and Net Worth applications.
